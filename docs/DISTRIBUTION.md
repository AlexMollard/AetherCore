# AetherCore private distribution

The repository owner has chosen to keep the engine private and defer selection of
an engine distribution license. No open-source license is granted for original
AetherCore code by this notice. Obtain owner authorization before redistributing
the engine or publishing release artifacts.

Third-party components remain governed by their own licenses. The generated
THIRD_PARTY_NOTICES.txt and accompanying license files travel with private packages;
this private status does not replace their terms. Sample-project assets have
separate credits in their projects and are not automatically licensed with the engine.

Release support, versioning and qualification rules are in docs/support-policy.md
in the source repository. A private package must include its provenance manifest
and identify unqualified platforms, unsigned status and known limitations.
