# UI Editor + In-Engine UI Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a retained-mode UI (text, image/quad, Unity-style anchoring) authored as ECS entities, rendered by an in-engine GPU backend, edited in a 2D Canvas panel with a live viewport overlay - plus scene quick-save (Ctrl+S) and New Scene (a cube dropping onto a static platform).

**Architecture:** UI elements are ECS entities (`UICanvas`/`UIRect`/`UIImage`/`UIText`) reusing the existing hierarchy, inspector, undo, and TOML serialization. A `UiLayoutSystem` resolves anchors top-down into pixel rects each frame; a `UiDrawBuilder` emits `DrawCommandData` (rects + per-glyph SDF) in painter order; a `UiRenderer` uploads them to a device-address buffer and draws them with the existing `ui_shapes.slang` in a `$UiOverlay` pass appended after FXAA into the post-process output. Text uses an offline FreeType SDF atlas baked by the `assetpack` tool.

**Tech Stack:** C++20, Vulkan (bindless, device address), Slang shaders, EnTT, FreeType, toml++, doctest, Dear ImGui.

---

## Refinements discovered while grounding the spec

Two deliberate deviations from `docs/superpowers/specs/2026-07-07-ui-editor-design.md`, both simplifications:

1. **No GPU sort in v1.** The CPU emits `DrawCommandData` in painter order (`layer = emission index`) and knows the count `N`, so `$UiOverlay` calls `cmd.Draw(6, N)` reading the command buffer by device address. The `ui_build_draws.slang` bitonic sort + indirect buffer (spec §4) are **redundant for v1** and deferred - they only matter once explicit/dynamic layer values reorder the buffer. `ui_shapes.slang` (the actual renderer) is used unchanged.
2. **UI system feeds the renderer via a stored `World*`**, mirroring `PhysicsDebugRenderer::m_world` (`PhysicsDebugRenderer.cpp:635`), rather than a new render-graph product.

namespace aether::app::scene
{
    std::string NewScene(World& world, const ApplySceneDeps& deps)
    {
        const auto text = io::FileSystem::ReadTextFile("scenes://default.scene.toml");
        if (!text.has_value()) return {};
        const auto desc = ParseToml(*text);
        if (!desc.has_value()) return {};
        ReplaceScene(*desc, world, deps);
        return desc->name.empty() ? std::string{"Untitled"} : desc->name;

                   const MaterialRegistry& materials, const TextureRegistry& textures,
                   const Renderer* renderer)
    {
        if (sceneName.empty()) return false;
        return SaveSceneFile(sceneName, CaptureScene(world, materials, textures, renderer));
    }
}

```cpp
#include "ui/UiLayoutSystem.hpp"
#include "scene/World.hpp"
#include "scene/Components.hpp"      // HierarchyComponent
#include "scene/Entity.hpp"

namespace aether::ui
{
    glm::vec4 ResolveRect(const glm::vec4& parent, const UIRect& r)
    {
        const glm::vec2 pMin{parent.x, parent.y};
        const glm::vec2 pSize{parent.z, parent.w};
        const glm::vec2 aMin = pMin + r.anchorMin * pSize;
        const glm::vec2 aMax = pMin + r.anchorMax * pSize;
        const glm::vec2 rMin = aMin + r.offsetMin;
        const glm::vec2 rMax = aMax + r.offsetMax;
        return {rMin.x, rMin.y, rMax.x - rMin.x, rMax.y - rMin.y};
    }

    static void ResolveSubtree(World& world, Entity e, const glm::vec4& parentRect)
    {
        glm::vec4 selfRect = parentRect;
        if (auto* rect = world.TryGet<UIRect>(e))
        {
            rect->resolvedRect = ResolveRect(parentRect, *rect);
            selfRect = rect->resolvedRect;
        }
        if (const auto* h = world.TryGet<HierarchyComponent>(e))
            for (const Entity child : h->children)
                ResolveSubtree(world, child, selfRect);
    }

    void ResolveCanvases(World& world, glm::vec2 outputExtent)
    {
        const glm::vec4 screen{0.f, 0.f, outputExtent.x, outputExtent.y};
        world.View<UICanvas, UIRect>().each([&](auto ent, UICanvas&, UIRect&) {
            const Entity e = World::FromEntt(ent);
            glm::vec4 canvasRect = screen;
            if (auto* rc = world.TryGet<UIRect>(e)) { rc->resolvedRect = screen; }
            if (const auto* h = world.TryGet<HierarchyComponent>(e))
                for (const Entity child : h->children)
                    ResolveSubtree(world, child, canvasRect);
        });
    }
}
```

        c.data0 = rect.resolvedRect; // x,y,w,h
        c.color = img.color;
        c.layer = layer;
        if (img.texture.IsValid()) {

            c.data1 = {0.f, 0.f, 1.f, 1.f}; // full UVs for v1
            c.textureSlot = 0; // resolved by UiRenderer at upload (see Phase 2)
        } else {
            c.type = kShapeRect;
            c.data1.x = img.cornerRadius;
        }
        out.push_back(c);
    }

    static void Walk(World& world, Entity e, int& layer, std::vector<UiDrawCommand>& out)
    {
        const auto* rect = world.TryGet<UIRect>(e);
        if (rect) {
            if (const auto* img = world.TryGet<UIImage>(e))
                EmitImage(*rect, *img, layer++, out);
            // UIText handled in Phase 3
        }
        if (const auto* h = world.TryGet<HierarchyComponent>(e))
            for (const Entity child : h->children)
                Walk(world, child, layer, out);
    }

    void BuildDrawCommands(World& world, std::vector<UiDrawCommand>& out)
    {
        out.clear();
        int layer = 0;
        world.View<UICanvas>().each([&](auto ent, UICanvas&) {
            Walk(world, World::FromEntt(ent), layer, out);
        });
    }
}

    void UiRenderer::EnsureCapacity(FrameBuffer& fb, std::uint32_t count)
    {
        const std::uint32_t need = count == 0 ? 1 : count;
        if (fb.handle.IsValid() && fb.capacity >= need) return;
        if (fb.handle.IsValid()) gpu::ResourceRegistry::Destroy(fb.handle);
        std::uint32_t cap = fb.capacity ? fb.capacity : 256;
        while (cap < need) cap *= 2;
        const gpu::MappedBufferDesc bd{
            .size = static_cast<gpu::DeviceSize>(cap) * sizeof(UiDrawCommand),
            .usage = gpu::BufferUsage::Storage | gpu::BufferUsage::ShaderDeviceAddress,
            .memoryUsage = gpu::MappedMemoryUsage::CpuToGpu,
            .debugName = "UI.Commands",
        };
        fb.handle = gpu::ResourceRegistry::CreateMappedBuffer(bd);
        const auto view = gpu::ResourceRegistry::ResolveMappedBuffer(fb.handle);
        fb.mapped = view.mappedPtr;
        fb.address = view.deviceAddress;
        fb.capacity = cap;
    }

    {
        m_extent = outputExtent;
        const auto slot = frameSlot % 3u;

        if (!m_world) return;
        ResolveCanvases(*m_world, outputExtent);
        BuildDrawCommands(*m_world, m_scratch);
        // TODO Phase 3: resolve UIImage.textureSlot / glyph atlas slot here.

            gpu::ResourceRegistry::FlushMappedBuffer(m_frames[slot].handle, 0, n * sizeof(UiDrawCommand));
        }
        m_count[slot] = n;

        if (extent.width && extent.height) pass.SetExtent(extent);

            .Execute([this, &bindless, slot](PassContext& ctx) {

            });
