# Testing Project

Project-root sample used to exercise the editor launcher, File Explorer, inspector drag/drop, scene save/load, and publishing.

Game assets live under `assets/`, scenes under `scenes/`, scripts under `scripts/`, and the project descriptor is `ProjectSettings.toml` at the project root.

For public SDK declarations and examples, see [Script APIs and examples](../../docs/getting-started.md#script-apis-and-examples).
